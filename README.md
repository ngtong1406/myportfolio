### Want to test it locally? I got you.

Type the following in your computer's terminal.

_Before you do this, please make sure you have [Node.js](https://nodejs.org/en/download) installed on your device._

```bash
# 1. Clone repo
git clone git@github.com:ngtong1406/toby-portfolio.git

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```
